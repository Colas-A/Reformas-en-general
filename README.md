# Reformas en General — web

Web de Reformas en General (Alcalá de Henares, Comunidad de Madrid): servicios, zona de trabajo, preguntas frecuentes y formulario de presupuesto por WhatsApp.

Sitio estático (HTML + imágenes), sin dependencias ni compilación. Se publica con GitHub Pages desde la rama `main`.

## Antes de publicar con dominio propio
- Sustituir `https://www.TU-DOMINIO.es` por el dominio real en `index.html`, `robots.txt` y `sitemap.xml`.
- Añadir el archivo `CNAME` con el dominio.
- Añadir aviso legal y política de privacidad.
